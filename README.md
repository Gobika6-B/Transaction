Transaction is a simple Java application designed to handle basic financial transaction operations. This project demonstrates how to model and process transactions in a structured object-oriented format using core Java.

In this project, users can:

 Record a transaction with details such as amount, transaction type (e.g., debit/credit), and date/time.

 Store and manage transaction data using Java classes and possibly collections (like ArrayList or List) to maintain all transaction records.

 Display or list transactions, providing an overview of financial activity.

 Use hands-on Java programming concepts such as classes, objects, methods, and basic data structures.

 This project is ideal for beginners learning Java who want to practise creating simple domain models (like a Transaction class), implement basic logic around financial records, and learn good coding structure and documentation practices.
